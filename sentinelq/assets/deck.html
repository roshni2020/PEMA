PEMA

Personal Environmental Memory Agent
A private, on-device memory of your room for people with low vision or memory loss.
Arduino UNO Q (Qualcomm Dragonwing) + Snapdragon Hexagon NPU via GenieX + STM32.
Roshni
Problem and solution

“Where is my phone?” “What is in front of me?” “Is the stove still on?”

The problem

  • 2 billion people have some vision impairment; 55 million live with dementia. They ask these questions all day.
  • Today's answer is a cloud camera: it streams your home to a server, costs a subscription, and doesn't know what is yours.
  • It notices people. It can't tell you your keys moved.

The solution: PEMA

  • A private, on-device memory of your room for people with low vision or memory loss.
  • Arduino UNO Q (Qualcomm Dragonwing) sees and remembers; a Snapdragon Hexagon NPU via GenieX reasons; an STM32 acts and verifies.
  • Knows one person by passphrase, stores object positions not video, works with no cloud.
What PEMA does

One loop

1
Identify. A passphrase stored on the board. No face data.
2
Remember. Objects seen by the Arduino, where they were, their usual spot.
3
Notice. Leave and return: “your keys moved to your right.”
4
Act. Turn the light on, warn, show an icon.
5
Verify. The microcontroller confirms before it says “done”.
Architecture

Qualcomm chips think and remember. The Arduino microcontroller senses and acts.

Camera + page

  • webcam frames
  • voice in and out
  • 3D map, timeline

Arduino UNO Q · Qualcomm Dragonwing

  • YOLOX object detection
  • memory and usual spots
  • leave / return detection
  • safety rules, whitelist
  • history (SQLite)

Hexagon NPU · GenieX

  • Qwen3.5-2B, 4-bit
  • planner, one tool per step
  • vision: “what is in front of me”
  • fixed output format

STM32

  • sensors every second
  • light, buzzer, LED matrix
  • reads state back
  • safety cut-off

Proof on every answer

Each reply carries the chip it ran on (HTP0, the Hexagon), tokens per second and time to first word. It is shown live on the dashboard.

What I optimised

4-bit model · fixed answer format, so no broken output · one model for thinking and seeing · short prompts, few steps · small frames one at a time. First word in 2 to 4 s, about 20 tokens/s.

Privacy and limits

Privacy by design

  • Built for low-vision users, not for watching people.
  • Frames are analysed on the device and discarded. Only object positions are stored, on the board.
  • Objects, not faces. Passphrase, not biometrics.
  • Camera off switch. No internet after setup.

Said honestly

  • The Arduino's chip has no supported NPU, so the model runs on the laptop's Hexagon. Same code on a Qualcomm board with its own NPU.
  • 80 object classes; doors and windows come from the vision model.
  • The 3D map is approximate placement, not a measured reconstruction.
